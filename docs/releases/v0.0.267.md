# v0.0.267

Manual Pick accepts a click while its automatic file inspection is running. The button immediately acknowledges the choice, waits for that same inspection, and saves the exact release once. An explicit choice receives any inspection failure instead of silently losing the click.

Ownership and eligibility checks still prevent selection of available or unverified-owned files. The existing submission confirmation, exact-release persistence, and acquisition policy are unchanged. AniDB evidence colouring is unchanged in this release.

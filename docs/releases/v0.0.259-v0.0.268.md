# v0.0.259 – v0.0.268

Detailed release notes for each version, newest first. Later versions are in [v0.0.269 – v0.0.328](v0.0.269-v0.0.328.md) and their own files.

## v0.0.268

Manual Pick automatically identifies globally listed AniDB release groups using AniMap's public global group list. Matching titles display a green AniDB group badge before file inspection. The tooltip and Details identify the evidence as global group registration, separate from show association and exact-file verification.

Full and short group names match exactly after case/whitespace normalization. Ambiguous aliases remain neutral. One shared six-hour cache serves both saved requests and unsaved previews; the global list is fetched alongside indexer discovery with a 1.5-second deadline and a short failure cooldown. No anime IDs, account details or release choices are sent in this global-list request.

No direct AniDB client, account credentials, additional dependency or user button is introduced. Optional lookup failures leave release choices usable. File Likely/Verified evidence, quality ordering, ownership and acquisition checks are unchanged.

## v0.0.267

Manual Pick accepts a click while its automatic file inspection is running. The button immediately acknowledges the choice, waits for that same inspection, and saves the exact release once. An explicit choice receives any inspection failure instead of silently losing the click.

Ownership and eligibility checks still prevent selection of available or unverified-owned files. The existing submission confirmation, exact-release persistence, and acquisition policy are unchanged. AniDB evidence colouring is unchanged in this release.

## v0.0.266

Manual Pick checks visible release rows automatically, one at a time with shared pacing, using the existing file inspection and bounded AniMap lookup. It stops queued work when the picker closes, a search is replaced, or Auto-Pick takes over. Offscreen results wait until scrolled into view. Provider failures stay unknown without an automatic retry loop or interrupting the search; Details retains an explicit retry.

A likely CRC32-and-exact-size AniDB match now colours the title and badge green, while preserving its Likely label and explanation. Previously verified exact files retain a distinct Verified label. Every selected video in a pack must have sufficient evidence; unknown or partially matched packs remain grey. Group names and filename predictions alone cannot turn a row green.

Background evidence uses a separately limited read-only route, preserving the explicit Pick/Auto-Pick command budget and avoiding draft-command coalescing. Browsing still creates no request or download. Inspection is shared with Details and Pick; ownership and fresh selection validation remain unchanged.

## v0.0.265

The active Pure download path now forwards exact-owner qBittorrent progress, speed, ETA and transfer state into the existing durable completion journal. Requests use those measured samples for the animated progress bar. Queued, stalled and paused downloads retain their own status, including qBittorrent 5 stoppedDL. Authentication failures clear the last sample; expired samples and completed handoffs cannot masquerade as live downloads. Existing completion, stop, file-move and Shoko/Plex verification safeguards remain in place, with no additional torrent reads or video probes.

Manual release inspection caches successful evidence and shares in-flight lookups, while failed provider/busy results remain retryable on the same search result. Retry inspection explicitly rechecks that result without another search, request or download. Successful inspection clears the old error, and replacing a search prevents its removed rows from changing the new results. Paginated rows remain usable.

The Requests-card Auto-Pick note now says evidence-backed option rather than describing likely AniDB correspondence as registered.

## v0.0.264

Legitimate repeated release-preview submissions return the existing request as success. Reopening the same command, a same-user Airing watch, or choosing from a second open preview preserves the existing request and exact saved release without another acquisition wake. The picker confirms the existing request and links to it. Conflicting commands, cancelled requests, another user's monitoring and access restrictions retain their guards. Existing success does not require another preview slot.

Auto-Pick alternative prompts distinguish **Likely AniDB match** (advertised CRC32 and size) from **Previously verified exact AniDB files**. The action and unattended timeout wording use that actual evidence level rather than calling a likely match a registered release. Unknown and likely evidence remain neutral; green remains reserved for previously verified exact files. Stored proposal/action keys stay compatible across upgrades.

Regression coverage confirms the v0.0.263 fallback deadline fix: repeated partial searches and restarts preserve the original two-hour expiry, dispatch the freshly revalidated fallback once at expiry, and reject changed torrent identity. A partial search alone cannot extend the expired wait.

## v0.0.263

Release quality ranks before the reported-peer threshold. A seeded 1080p release no longer loses to 480p or 720p solely because it reports two seeders instead of three. Zero-seeder releases remain excluded; 720p and older SD releases remain available as fallbacks. Source, trusted-uploader and peer preferences still apply. Recognition preference cannot lower the resolution across that threshold.

Completed-series Manual Pick puts advertised packs first and enables **Season packs only** by default. Filtering and ordering happen before the bounded candidate cap and pagination. Turn the checkbox off to reveal individual episodes for fallback. Releases with unspecified coverage remain visible, including unlabelled BD packs. Pack labels are advertised hints; file inspection separately reports how many requested episodes the plan covers. BD/1080p+ and audio controls remain available. Airing and film searches retain their existing behavior.

Auto-Pick with a saved active-watch group preference uses the normal acquisition worker and its durable per-episode two-hour deadline. Mode changes, restarts and unknown release dates do not erase the wait. Historical catch-up stays immediately eligible, and late preferred releases cannot duplicate active targets. Fresh previews retain their preference when committed. At deadline expiry, an exact saved fallback is freshly revalidated and cannot remain postponed solely by partial search results.

## v0.0.262

A saved Auto-Pick or Manual Pick choice becomes eligible immediately after an earlier empty release search. The queue records the selection revision at claim time, so a choice made during a running search or before a restart is preserved. Each unchanged choice gets only one early check; existing active claims, ownership, suspension and provider/import safety gates remain enforced.

This follows v0.0.261's pack evidence, episode scope, shared language rules and torrent compatibility fixes.

## v0.0.261

Acquisition checks for a new season use bounded target reads and reuse positive AniDB identity metadata only within one observation. Local file availability is still read twice, public health is still checked twice, and existing evidence-freshness checks remain. Transient stale-evidence retries are scheduled after one minute, including existing saved rows.

Absolute-numbered packs require either exact per-file Shoko filename predictions or an independently established regular-episode prequel chain matching the proposed offset. Matching titles and file counts alone cannot authorize an offset. Preview and final submission both enforce the rule; older candidate-check cache results are not reused. Unknown AniDB registration still does not block correctly scoped releases.

Auto-Pick and Manual Pick share explicit language-suitability rules. Explicit incompatible dubs and declarations of no subtitles are excluded; unknown language tags, burned-in subtitles and Japanese/English dual-audio options remain supported. Explicit English-dub selection remains available through its manual filter.

Torrent preflight accepts numeric ordinal padding paths under the documented BitTorrent padding flag without changing the original info hash. Clearly labelled standalone opening/ending extras no longer invalidate a complete season's regular-episode plan. Unsafe paths, unsupported file attributes, conflicting episodes and final Shoko/Plex identity checks remain protected.

## v0.0.260

A complete absolute-numbered season pack no longer fails solely because Offline Importer consistently predicts an earlier episode in the same anime. The existing complete-pack file plan remains authoritative for provisional scope, and this prediction is labelled uncertain rather than registered or exact. Different anime, mixed offsets, incomplete packs and invalid preview evidence remain rejected.

Actual downloaded-file identification, pinned torrent and file guards, Shoko import checks and Plex verification are unchanged. Cached preview rejections from the previous policy are not reused.

## v0.0.259

Manual Pick now opens an unsaved preview: browsing, closing, and changing preferences do not submit a request. An explicit Pick or Auto-Pick commits the request and choice atomically, with current permissions, availability and duplicate checks. Existing saved requests retain their choices.

Release search includes bounded same-title alternate spellings and preserves group refinements across official aliases. Quality and audio filters apply before pagination. Auto-Pick shows a prominent submitted confirmation and a direct request link.

Complete installment packs can provisionally map a consistent absolute episode sequence to the installment's full regular episode list. Partial or conflicting packs and contradictory Shoko identity predictions remain rejected; this is not exact AniDB file verification.

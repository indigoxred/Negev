# v0.0.331

Faster page loads, clearer menus and filters, and admins can now delete accounts.

**Faster loads.** Pages, scripts, stylesheets and fonts are compressed with Brotli or gzip, and the browser revalidates them instead of downloading them again. A first visit now transfers about 212 KB instead of 748 KB (`app.js` 198 KB → 36 KB, the four fonts 358 KB → 130 KB). On a repeat visit, unchanged files return 304 Not Modified with no body. Fonts are cached for a week. Static files contain no account data.

**Interface.**
- The account menu toggles have fixed labels with an on/off switch: **Show 18+ titles**, **Show Chinese productions**, **Show English titles**.
- Discover and Airing filters apply as soon as you change them, and the **Apply filters** buttons are gone. Several quick genre clicks are combined into one update. A pending update is dropped if you leave the page.
- Admin review shows each hold's reason in plain English. Hover over it to see the internal code.
- Page headings match the navigation (**Library**, **Requests**). The request tabs are **Recent** and **Watching**.

**Delete accounts.** Disable an account first, then use **Delete account** in Administration. In one transaction, this removes the account, its sessions and preferences, its password reset links, its pending title requests and parent-show watches, and every request of theirs that never started a download. A request that already started a download stays as history, because its records describe files already in Plex or still downloading, and it stops watching for new episodes. An admin cannot delete their own account. Deletion cannot be undone.

**Internal.**
- Browser test fixtures serve `public/` from the directory, as the server does.
- New modules: `src/web/static-asset.mjs`, `src/web/public/review-reason.mjs` and `src/auth/delete-account.mjs`.

**Upgrade and rollback.**
- No schema changes. Rolling back to v0.0.330 is safe. Deleted accounts stay deleted.
- The install example now pins v0.0.330.

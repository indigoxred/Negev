# v0.0.266

Manual Pick checks visible release rows automatically, one at a time with shared pacing, using the existing file inspection and bounded AniMap lookup. It stops queued work when the picker closes, a search is replaced, or Auto-Pick takes over. Offscreen results wait until scrolled into view. Provider failures stay unknown without an automatic retry loop or interrupting the search; Details retains an explicit retry.

A likely CRC32-and-exact-size AniDB match now colours the title and badge green, while preserving its Likely label and explanation. Previously verified exact files retain a distinct Verified label. Every selected video in a pack must have sufficient evidence; unknown or partially matched packs remain grey. Group names and filename predictions alone cannot turn a row green.

Background evidence uses a separately limited read-only route, preserving the explicit Pick/Auto-Pick command budget and avoiding draft-command coalescing. Browsing still creates no request or download. Inspection is shared with Details and Pick; ownership and fresh selection validation remain unchanged.

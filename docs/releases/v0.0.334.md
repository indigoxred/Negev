# v0.0.334

Completes server and browser enforcement of the administrator's 18+ account permission.

- New reservations, stopped-torrent additions and download starts check fresh title classification, including retained bonus titles, and the current enabled request owner's permission. Unknown classification holds new work for verification.
- Permission holds preserve requests, saved selections and claims across restart. Re-enabling access resumes normal checks. Existing uncertain sends remain one-send, and already-started downloads can complete and publish; revocation does not delete torrents or files.
- Metadata, artwork, related and browse lists, history and release controls recheck current actor and owner access, including changes during provider reads and final response preparation. Restricted or unknown history keeps safe identity, status and cancellation controls.
- The browser refreshes current permissions on relevant responses and visible minute checks, clears revoked metadata and retained cards, and invalidates pending responses. Unchanged checks preserve typed work; re-enabling access preserves personal hiding preferences.
- Regression coverage includes provider and response races, retained bonuses, rejected-send retries, restart recovery, safe all-ages access and browser revocation. The account policy is documented in [Account 18+ access](../adult-access-policy.md).

**Upgrade and rollback.** No schema migration or dependency change is introduced by this release. Preserve a matched stopped-service backup of the database, signing key, credentials and container/template configuration, and retain the v0.0.333 image. Rolling back restores the earlier permission behavior; keep the new release when current 18+ enforcement is required. This release does not upgrade Shoko.

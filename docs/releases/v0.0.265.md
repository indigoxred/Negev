# v0.0.265

The active Pure download path now forwards exact-owner qBittorrent progress, speed, ETA and transfer state into the existing durable completion journal. Requests use those measured samples for the animated progress bar. Queued, stalled and paused downloads retain their own status, including qBittorrent 5 stoppedDL. Authentication failures clear the last sample; expired samples and completed handoffs cannot masquerade as live downloads. Existing completion, stop, file-move and Shoko/Plex verification safeguards remain in place, with no additional torrent reads or video probes.

Manual release inspection caches successful evidence and shares in-flight lookups, while failed provider/busy results remain retryable on the same search result. Retry inspection explicitly rechecks that result without another search, request or download. Successful inspection clears the old error, and replacing a search prevents its removed rows from changing the new results. Paginated rows remain usable.

The Requests-card Auto-Pick note now says evidence-backed option rather than describing likely AniDB correspondence as registered.

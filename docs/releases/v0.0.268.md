# v0.0.268

Manual Pick automatically identifies globally listed AniDB release groups using AniMap's public global group list. Matching titles display a green AniDB group badge before file inspection. The tooltip and Details identify the evidence as global group registration, separate from show association and exact-file verification.

Full and short group names match exactly after case/whitespace normalization. Ambiguous aliases remain neutral. One shared six-hour cache serves both saved requests and unsaved previews; the global list is fetched alongside indexer discovery with a 1.5-second deadline and a short failure cooldown. No anime IDs, account details or release choices are sent in this global-list request.

No direct AniDB client, account credentials, additional dependency or user button is introduced. Optional lookup failures leave release choices usable. File Likely/Verified evidence, quality ordering, ownership and acquisition checks are unchanged.

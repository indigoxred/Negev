# Shoko-first identity fallback

Negev prefers Shoko's exact AniDB file result. An inconclusive lookup is not a wrong-file verdict and must not retire or replace a completed download. This policy follows the owner's November 2026 clarification: AniDB registration helps recognition but is not a requirement for every encode, especially while a show is airing.

For a completed candidate, retain the qBittorrent manifest, selected file names, file sizes and hashes. If exact AniDB file identity is unavailable, use the request's AniDB anime and episode targets, the selected release's episode claim, and Shoko's catalogue identities to decide whether a limited Shoko handoff is plausible. A title string alone is insufficient. Keep the provisional state distinct from an exact-file match. Before publishing, recheck the torrent, file bytes, target scope and private mounts; never silently reuse an exact-release manifest for a provisional one.

After Shoko hashes the imported file, look it up by ED2K and size through its supported API. Give Shoko time to assign its own release. If it assigns the correct release, continue normally. If it assigns a conflicting identity, hold the attempt and do not overwrite it. If it remains unrecognized, try a configured Shoko release provider such as Offline Importer against that exact file and compare its returned anime and episode IDs with the request. An interactive preview is evidence that a provider can parse the file; it does not prove that Shoko will accept it automatically. Use the provider's supported automatic rules in a scoped pilot, or save an exact, verified provider result after a second file/release read. Do not synthesize a User release from Negev's own filename guess as the ordinary fallback. Never overwrite an existing release, infer multi-episode coverage, or link an unrelated file sharing a name.

An import is successful only after the same Shoko file appears as playable under the correct public Plex show. Availability and request completion continue to use that public evidence. Ambiguous cases remain held without blocking later items. A held download must not be deleted or redownloaded solely because the exact-file lookup returned 204.

The installed Offline Importer is currently disabled and has no automatic allow rules. A read-only preview of unrecognized Shoko file 19767, whose name claims The Detective Is Already Dead S02E05, returned AniDB anime 17527 and episode 317982 (Shoko's Season 2 episode 5) in interactive mode, but 204 in automatic mode. The plugin source confirms that automatic mode returns no match when its allow-rule list is empty. Its rule model supports a managed-folder ID plus relative-path prefix; a Negev-only pilot would use managed folder 1 and `/Negev`, with the provider behind AniDB in priority. No Negev file currently sits in that Import subfolder, so a positive automatic-mode preview still needs a genuine test arrival. This proves one plausible stock fallback and identifies the missing rule; it does not prove automatic arrival or justify a global allow rule. Production stays on the current exact-file path until isolated tests prove arrival, late recognition, conflicting recognition, crash recovery, withdrawal and public Plex proof for both series and movies. The existing Airing episode is the first genuine Negev candidate for the revised path; its content identity is not yet independently proved.
